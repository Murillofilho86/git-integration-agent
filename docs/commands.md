# Command Reference

This document describes every command currently available in the Git Integration Agent.

Each command represents one stage of the integration workflow.

---

# Overview

```
analyze

↓

plan-feature

↓

run-task

↓

integrate-feature
```

The commands are designed to be composable.

Each command performs one specific responsibility.

---

# analyze

Analyzes the differences between two Git branches.

## Syntax

```bash
python app.py analyze \
    --repo "<repository>" \
    --from feature \
    --to target
```

## Parameters

| Parameter | Description |
|------------|-------------|
| --repo | Local Git repository |
| --from | Source branch |
| --to | Target branch |

## Output

Produces:

- repository analysis
- metadata
- file list
- integration classification

---

# plan-feature

Generates an implementation plan.

## Syntax

```bash
python app.py plan-feature \
    --repo "<repository>" \
    --from feature \
    --to target
```

## Output

Produces:

- task plan
- execution order
- workspace
- task metadata

---

# run-task

Executes a single implementation task.

## Syntax

```bash
python app.py run-task \
    --workspace workspace/... \
    --repo "<repository>" \
    --from feature \
    --to target \
    --task 1
```

## Parameters

| Parameter | Description |
|------------|-------------|
| --workspace | Existing workspace |
| --task | Task identifier |

## Output

Produces:

- prompt
- AI response
- generated files
- execution history

---

# integrate-feature

Executes every task generated by the planner.

## Syntax

```bash
python app.py integrate-feature \
    --repo "<repository>" \
    --from feature \
    --to target
```

## Output

- complete implementation
- consolidated generated files

---

Prefer executing tasks individually during development.

This simplifies debugging and allows interrupted executions to be resumed.
